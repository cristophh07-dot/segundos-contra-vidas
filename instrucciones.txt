1. QUÉ ES
   Un análisis de datos abiertos de Medellín que muestra en qué vías salvaría más vidas bajar
   la velocidad o separar a las motos, y cuántos segundos le costaría a cada conductor.
   El notebook principal es notebooks/segundos_contra_vidas.ipynb.

2. PROBARLO EN LÍNEA

   gráficas y resultados. Abrir en el navegador:
       https://github.com/cristophh07-dot/segundos-contra-vidas/blob/main/notebooks/segundos_contra_vidas.ipynb
   Si GitHub no lo muestra ("Unable to render"), el mismo notebook se ve en:

3. EJECUTARLO
   Requisitos
   - Python 3.13. Sirve con o sin Anaconda:
       · Anaconda (trae Python y Jupyter): https://www.anaconda.com/download
       · Python solo: https://www.python.org/downloads/
         En Windows, al instalar, marcar la casilla "Add python.exe to PATH".
   - Conexión a internet. No hay que descargar datos a mano: el código los baja solo desde las
     fuentes oficiales (unos 370 MB la primera vez).
   - Probado en Windows con Anaconda; versiones exactas de las librerías en requirements.txt.

   Pasos
   1) Descargar el repositorio: en https://github.com/cristophh07-dot/segundos-contra-vidas
      botón verde "Code" → "Download ZIP", y descomprimir la carpeta.
      (Con git: git clone https://github.com/cristophh07-dot/segundos-contra-vidas.git)
   2) Abrir una terminal dentro de esa carpeta ("Anaconda Prompt", o "Símbolo del sistema"
      sin Anaconda) y escribir, cambiando la ruta por la suya:
          cd C:\ruta\a\segundos-contra-vidas
   3) Instalar las librerías (una sola vez; tarda unos minutos):
          python -m pip install -r requirements.txt
   4) Abrir Jupyter (se abre en el navegador) y entrar a la carpeta notebooks/:
          python -m notebook
   5) Correr estos notebooks en orden. En cada uno: menú "Run" → "Run All Cells", y esperar a
      que termine antes de abrir el siguiente:
          a) 03_exponente_medellin.ipynb
          b) 05_prediccion.ipynb
          c) 06_montecarlo.ipynb
          d) segundos_contra_vidas.ipynb   ← NOTEBOOK PRINCIPAL
      Los tres primeros calculan los resultados que usa el principal. Si falta alguno, la
      primera celda del principal dice cuál correr. Los notebooks 01, 02 y 04 son anexos.

   Si algo sale mal
   - "python no se reconoce": reinstalar Python marcando "Add python.exe to PATH", o usar
     Anaconda Prompt.
   - Hay varias versiones de Python: usar  py -3.13 -m pip install -r requirements.txt
     y  py -3.13 -m notebook
   - Falla una descarga: revisar la conexión y comprobar las fuentes con
     python -m src.verificar_fuentes   (cada una debe salir [OK]).
   - Error después de una ejecución interrumpida: borrar las carpetas data/cache/ y
     data/processed/ y repetir el paso 5.
   - Es normal que la primera vez tarde varios minutos: está descargando los datos.

4. QUÉ DEBE VER EL JURADO
   Al final del notebook principal, en "Cierre · Lo que proponemos":
   - En solo 3 vías (Avenida Regional, Autopista Sur y Autopista Norte), un tope de 50 km/h
     con control permanente y un carril exclusivo de motos salvarían unas 5,7 vidas al año
     (entre 4,4 y 7,1) y evitarían unos 372 incidentes graves al año: 1 de cada 4 en esas vías.
   - El costo es de segundos: 57 s por viaje en la Regional y entre 4 y 16 s en las autopistas.
   Y en el paso 2, el mapa: 294 de los 1.541 muertos de 2019–2024 cayeron sobre 12 vías, y 143
   (el 49%) sobre esas 3. Las cifras de vidas salen de 10.000 simulaciones (Monte Carlo); por
   eso cada una va con su intervalo.
